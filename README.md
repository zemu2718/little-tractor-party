# 齐齐的生日派对 🐲

与家中挖掘机主题布置一致：一个入口、一套生图视觉，集合生日迎宾、成长相册、生日歌、吹蜡烛、亲子互动和合影。打开 `index.html` 就进入生日主画面，不再需要选择版本。

## 已确认的家庭设定

- 展示名：**齐齐**，两周岁，生肖龙；戴皇冠的友善中国小龙代表宝宝。
- 妈妈生肖鼠：奶油色小老鼠、绿色裙子和格纹蝴蝶结。
- 爸爸生肖鸡：金黄色公鸡、红鸡冠、绿色尾羽；**齐齐驾驶黄色玩具履带挖掘机，爸爸妈妈在旁边陪伴庆祝**。
- 主标题：**齐齐，生日快乐！**，使用透明底生图艺术字，带轻柔入场和缓慢起伏动效。相册与亲子互动标题也使用同风格生图艺术字；年龄只通过画面数字与蜡烛表达。

全站插画、角色、艺术字、图标和独立火苗均来自生图 PNG，网页使用保留透明度的 WebP 减少加载体积。旧的三个版本目录、版本选择页、全部 SVG 文件和矢量插画生成脚本已移除。按钮、歌词、文件名字幕与操作提示使用网页文字，便于阅读和实时更新。

## 使用方式

1. 浏览器打开 `index.html`，手机横屏。
2. 点击主操作栏的 **「全屏展示」**。支持的浏览器进入全屏后会隐藏操作栏；轻点空白处找回，再点「退出全屏」。
3. 需要电视展示时，用手机系统的屏幕镜像连接电视；网页本身不发起投屏。手机屏幕比 16:9 更宽时，两侧用当前场景的模糊放大图铺满，投屏不会出现空边。
4. **iPhone** 的 Safari 不支持网页全屏：点「分享 → 添加到主屏幕」，之后从桌面图标「齐齐生日」打开即无浏览器工具栏（由 `manifest.webmanifest` 提供）。
5. 不支持网页全屏时会提示横屏、收起浏览器工具栏并使用系统屏幕镜像。画面始终保持 16:9，不裁切主体。
6. 点「全屏展示」或「给齐齐玩」会自动尝试保持屏幕常亮；「更多设置与备用图」中也可手动开关常亮，或提前保存派对、蛋糕备用图。

全屏通过用户点击调用标准 Fullscreen API，并兼容支持 WebKit 全屏入口的浏览器。不同手机系统可能不开放网页全屏；不能保证所有设备都能隐藏系统和浏览器工具栏。常亮通常需要 HTTPS，失败时请在系统设置中暂时延长自动锁屏时间。

## 四个场景

| 场景 | 功能 |
| --- | --- |
| 挖掘机乐园 | 小龙齐齐开黄色玩具挖掘机，公鸡爸爸与鼠妈妈在旁边庆祝；插画缓慢推拉、星星闪烁、气球不断飘起（点一下“啵”地爆开）；点挖掘机会震动并“嘟嘟”，点小龙、爸爸、妈妈、数字 2 会说话并爆出星星；每隔一会儿有小挖掘机沿底部颠簸开过，点它会按喇叭跳一跳；空闲 6 秒后能点的地方轮流闪金光星星并语音邀请“齐齐，点点挖掘机！” |
| 成长相册 | 本地选图、自动循环、上一张/下一张、字幕开关；照片慢速推拉，背景是当前照片的模糊铺底，鼠妈妈和小龙贴纸陪看，花瓣飘落；未选音乐时播放内置轻快八音盒音乐（可关闭）；支持 MP4/MOV/WebM 小视频（带原声，播完自动下一张）；换照片时语音“看，这是齐齐！”，点照片会爆星星并夸“齐齐好棒！” |
| 生日蛋糕 | 火苗跳动并带暖光；生日歌带低音、和弦与沙锤伴奏，歌词大字逐字高亮；「3·2·1 吹蜡烛」大字倒数后吹灭：火苗歪倒、冒烟、数字 2 闪金光、礼花炮与欢呼；点蛋糕即可倒数吹蜡烛，吹灭后再点重新点亮；唱歌时整幅画面随节拍弹动并冒出音符 |
| 点点玩 | 角色平时轻轻摇摆；每次点击轮换台词和动作（弹跳、转圈、扭一扭）并爆出彩色星星；空闲约 9 秒后进入「找一找」：问“妈妈在哪里呀？”，3 秒后目标发光提示，点对即庆祝，点错也只是正常打招呼；与「躲猫猫」交替：大家缩进草地，再一个个“哇”地弹出来（提前点到会立刻弹出）；点挖掘机会轰隆隆开出画面再从另一边开回来；右侧 ♫ 按钮开 16 秒跳舞派对，四个角色按节拍扭动、音符飞舞，结束撒花；草地上飘着可以戳破的彩虹泡泡 |

「撒花庆祝」是从两侧喷出的礼花炮加彩纸雨（约 140 片，多种形状），配“砰”和欢呼音效，可在任一场景手动触发；切换场景时小挖掘机开过画面把新场景推进来。「合影模式」暂停动画、相册及音频，清除彩纸并隐藏按钮。轻点空白处只恢复操作栏，退出合影才恢复之前的展示状态。主插画整体缓慢推拉（不模拟图片内部车轮转动）；气球、星星、彩纸、花瓣为网页实时绘制的装饰。合影、暂停、切后台或「动效：安静」时全部停止。

宝宝连拍时每一下都有星星和动作，只有说话做 0.45 秒节流，避免声音叠在一起。公鸡、老鼠、小龙、挖掘机先发出合成叫声（喔喔喔、吱吱吱、嗷呜、轰隆隆），再说台词；有家人录音时直接放录音。

「给齐齐玩」直接进入互动并隐藏家长控制，同时自动打开声音、尝试常亮；左侧三个大圆图标可让宝宝自己切换挖掘机乐园、蛋糕和点点玩；轻点空白处会冒出星星和叮当声，不会打开菜单。亲子模式会拦截浏览器“返回”（包括边缘滑动），整个画面禁止下拉刷新、双指缩放、长按选字和“保存图片”菜单。长按右下角「家长 · 长按恢复」约一秒，或按 Esc 恢复操作。

**键盘：**Esc 恢复操作栏，H 显示/隐藏按钮，1–4 切场景；相册方向键翻页、空格播放/暂停；蛋糕场景空格吹蜡烛。点点玩中的角色按钮会继续互动，找回菜单时请点空白处。

## 照片、音乐与隐私

- 照片、音乐和家人录音仅使用浏览器本地文件地址，不上传、不写入仓库，不保存到服务器。刷新或关闭网页后需要重新选择。
- 照片和小视频按文件名自然排序，默认每张 8 秒，可改 5 或 12 秒。可用 `01-刚出生.jpg` 等命名控制顺序。
- 最多 120 个，照片每张不超过 25 MB、视频每段不超过 400 MB，总量不超过 1.5 GB，单张不超过 5000 万像素；逐张解码，损坏或超限文件会跳过。导入时显示进度，可以取消；取消或整批失败时保留已有相册。
- 支持 JPG、PNG、WebP、AVIF、BMP 等静态照片，不导入 GIF 动图。建议使用 JPG/PNG。HEIC/HEIF 的显示取决于设备；不支持时请先转换格式。
- 声音默认关闭（浏览器要求先点击）；「给齐齐玩」「一起唱生日歌」会自动打开。所有音效、生日歌与相册内置音乐均为本地合成，无网络音频，主音量已针对投屏电视调高并加限幅防破音。音乐只在相册场景播放；切后台、进入合影或关闭声音会停止或暂停相关声音。
- **页面内录音（推荐）**：「更多设置」里点「录妈妈」「录爸爸」「录齐齐/小龙」「录全家唱生日歌」，再点一次结束，录好立即回放。每个角色最多 4 段、每段 10 秒，点角色时轮流播放；生日歌最长 90 秒。需要允许麦克风，并通过 HTTPS（如 GitHub Pages）或局域网地址打开。推荐妈妈学小老鼠“吱吱吱，齐齐，妈妈爱你！”，爸爸学公鸡“喔喔喔，齐齐，爸爸陪你玩！”。
- 角色可使用设备已有的离线中文语音（音调稍高、语速稍慢，更像童声），缺少可用语音时播放短音效。也可选择妈妈、爸爸、齐齐的音频文件替代角色语音；每段不超过 10 MB，播放最多 12 秒。还可以选择一段全家唱的《生日快乐》录音（不超过 30 MB），唱歌时优先播放并按时长显示歌词。连续点击会停止上一段，避免重叠；关闭「角色说话」可只保留音效。录音不上传，刷新后需重选。

## 吹蜡烛

蛋糕图中的蜡烛原本未点亮，透明火苗图片独立叠加。「3·2·1 吹蜡烛」先大字倒数再吹灭，「直接吹灭」立即吹灭；吹灭时火苗歪倒熄灭、冒烟并撒花。点击「重新点亮」或直接点蛋糕即可恢复。切换场景保留蜡烛状态，不强制倒计时。

动效默认「热闹」，即使手机开启了“减弱动态效果”也保持派对动画；「更多设置 → 动效」可切换为「安静」，关闭所有动画、彩纸、气球与转场。

仅「更多设置 → 开启吹气感应」会申请麦克风。开启后校准约 1.5 秒，检测持续声音强度；现场说话、音乐也可能触发，因此手动按钮始终保留。离开蛋糕、进入合影、切后台或吹灭后会关闭麦克风，不自动重新申请。

## 离线与本地预览

不依赖外部图片、字体或脚本。`little-tractor-party-offline.zip` 解压后打开其中的 `index.html`，不要在压缩包预览器中运行网页。手机直接打开本地 HTML 的支持情况取决于系统；首次测试可使用同一局域网：

```bash
python3 -m http.server 8080 --bind 0.0.0.0
```

电脑访问 `http://localhost:8080`；手机访问 `http://电脑局域网IP:8080`。电脑需保持运行，防火墙需允许访问，结束后按 Ctrl+C。

两张备用图位于 `assets/birthday-background-4k.png` 和 `assets/birthday-cake-4k.png`，可以保存到相册断网展示。它们是生图背景、艺术字和火苗的 **3840×2160 排版导出**；原始生图并非原生 4K。备用图没有操作栏、实时字幕与动态效果，蛋糕图为蜡烛点亮状态。

## 文件与维护

```text
index.html                 唯一入口：四个场景及控制栏
manifest.webmanifest       添加到主屏幕后全屏横屏打开（iPhone 无网页全屏时使用）
styles.css                 响应式布局、艺术字/火苗/角色动效
app.js                     场景、相册、生日仪式、全屏、常亮
audio.js                   本地合成生日歌和短音效
voice.js                   离线中文语音与临时家人录音
assets/                    最终生图素材、两张备用图与主屏幕图标 app-icon.png
scripts/image-prompts.json 内置 image_gen 提示词和设计记录（不发布）
scripts/export_background.py 备用图排版导出（需要系统 Cairo）
scripts/check_play.cjs      交互/相册/全屏/生命周期回归
scripts/check_audio.cjs     音频启用、停止与后台静音检查
scripts/check_voice.cjs     本地语音、录音替换、连续点击与资源释放
scripts/optimize_assets.c   生成保留透明度的运行时 WebP
scripts/check_site.py       路径、昵称、PNG、无旧版本/SVG检查
scripts/package_site.py     单一版本白名单打包
.github/workflows/pages.yml GitHub Pages 检查与发布工作流
```

图片通过内置 `image_gen` 生成和编辑。提示词核心是“温暖的 3D 黏土/毛毡生日挖掘机乐园，戴皇冠的中国小龙齐齐驾驶黄色玩具履带挖掘机，公鸡爸爸和鼠妈妈在旁边庆祝，金色数字 2，一家人靠近陪伴，挖掘机统一圆润毛毡玩具质感，蛋糕页齐齐独立站立但与父母身高接近，顶部留白叠加精确中文艺术字”。完整提示词与中间风格迭代记录保存在 `scripts/image-prompts.json`，发布包只包含最终素材。

运行检查和打包：

```bash
node scripts/check_audio.cjs
node scripts/check_voice.cjs
node scripts/check_play.cjs
python3 scripts/check_site.py
python3 scripts/package_site.py
```

替换最终生图后，先更新对应的 WebP，再运行 `python3 scripts/export_background.py` 更新备用图；若修改标题或火苗位置，保持该脚本与 `styles.css` 的排版坐标一致。然后重新检查、打包。

`dist/` 是发布目录，包含网页、运行资源和离线包；输出目录和 ZIP 不加入 Git。运行时图片与脚本使用相对路径，支持 GitHub Pages 仓库子路径。只发布白名单文件，不包含提示词、开发脚本、私人照片或未使用的生图迭代。
