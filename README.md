# 齐齐的两岁快乐农场 🚜🐲

给 **齐齐** 的两周岁生日网站。齐齐生肖属龙，因此用一只戴金色小皇冠、笑眯眯的小龙作为三个版本共同的伙伴，陪他坐拖拉机、认识农场动物、看成长照片和庆祝生日。

主要用途：**手机打开网站 → 选择喜欢的版本 → 横屏 → 用系统屏幕镜像投到大厅电视**，作为迎宾、生日仪式、互动和合影背景。

网站采用原生 HTML、CSS、JavaScript 和 SVG；无需安装前端依赖，没有后端、广告、统计脚本或网络字体。已托管于 **GitHub Pages**。

**在线入口：[齐齐的两岁快乐农场](https://zemu2718.github.io/little-tractor-party/)**

大屏页面的「更多设置」提供版本选择入口。切换版本会打开另一个页面，**照片、音乐、蜡烛、全屏和常亮状态不跨版本继承**。游乐园载入了照片或音乐时，会先提示再返回首页。

## 生日当天怎么用

### 活动开始前

1. 打开首页，把「农场备用图」「蛋糕备用图」存到手机相册。
2. 需要电脑离线运行时，下载完整离线包，**先解压，再打开其中的 `index.html`**。不要在压缩包预览器里运行页面。
3. 手机连接现场网络，横屏打开选好的版本，再用系统屏幕镜像连接电视。
4. 检查名字是否清楚、画面是否完整、浏览器工具栏是否遮挡，并试一次切换蛋糕和合影。
5. 按需开启「保持屏幕常亮」「全屏展示」。不支持常亮时，在手机系统中暂时延长自动锁屏时间。

### 迎宾 → 蛋糕 → 合影

| 环节 | 操作 |
| --- | --- |
| 迎宾 | 进入欢乐派对，点击「隐藏按钮」，让小龙和拖拉机陪大家等待 |
| 切蛋糕 | 轻点空白处恢复按钮，选择「生日蛋糕」；唱歌与许愿由家人自行安排 |
| 吹蜡烛 | 大人点击「吹灭蜡烛」；祝福改变、彩纸落下、操作栏隐藏 |
| 重来一次 | 恢复操作栏，点击「重新点亮」 |
| 全家合影 | 点击「合影模式」，动画暂停、彩纸清除、操作栏隐藏 |
| 继续展示 | 轻点空白处恢复按钮，点击「退出合影」恢复进入前的动画状态 |

派对版和简洁版默认无声音，也不会请求麦克风。两版另有「撒花庆祝」按钮，可以在农场场景手动庆祝。暂停、合影或系统开启“减少动态效果”时，不播放彩纸。

**找回按钮：**轻点画面空白处，或在电脑上按 `Esc`。按 `H` 可显示／隐藏操作栏。游乐园里的动物按钮会继续响应互动，恢复菜单时请点动物以外的空白区域。

## 小龙游乐园操作说明

### 成长相册

1. 进入「成长相册」，点击「选择照片」，可多选；电脑也可把照片拖入页面。
2. 照片按文件名自然排序；需要明确顺序时，使用 `01-刚出生.jpg`、`02-第一次坐拖拉机.jpg` 等名称。
3. 默认每张停留 **8 秒**，循环播放。可在设置中改为 5 或 12 秒。
4. 「上一张」「下一张」「暂停相册」都有手机触控按钮。电脑也可用方向键翻页、空格播放／暂停。
5. 字幕来自文件名，常见相机自动命名会隐藏；设置中也可关闭全部文件名字幕。
6. 可选择本地背景音乐，再点「播放音乐」。音乐循环播放，只在相册场景播放；离开相册、进入合影或切后台时暂停。

照片和音乐通过浏览器本地文件地址使用，**不上传、不写入仓库，也不保存到服务器**。刷新、关闭页面或切换版本后，需要重新选择。重新选择照片会替换已有相册；「清空照片」释放当前照片资源。

为控制手机内存，相册最多载入 **120 张**，每张不超过 **25 MB**，选入总量不超过 **250 MB**，单图不超过 **5000 万像素**。文件会逐张解码检查；不支持、损坏或超限的文件会跳过并提示。如果整批都失败，保留已有相册。

推荐提前准备 JPG 或 PNG。HEIC／HEIF 是否可显示取决于设备与浏览器，不能保证；无法显示时请转换为 JPG。文件夹选择也取决于浏览器支持，普通多选照片始终作为主要入口。

### 生日歌和蜡烛

- 默认静音。「声音：开」启用互动音效；「一起唱生日歌」会主动开启声音并播放合成伴奏、同步显示歌词，家人可一起唱。
- 可以停止歌曲，也可以随时点击「吹灭蜡烛」，不必等待歌曲结束。
- 切场景、关闭声音、进入合影或切后台会停止生日歌；回来后需要重新开始唱。
- 吹灭后可重新点亮；同一页面内切换场景保留蜡烛状态。
- 「更多设置 → 开启吹气感应」才会请求麦克风。授权后先校准约 1.5 秒，再检测持续声音强度。
- 感应检测的是响度，现场讲话、音乐或其他噪声也可能触发；**手动按钮是现场可靠的操作入口**。不支持或拒绝权限时，照样可以手动吹灭。
- 离开蛋糕、吹灭蜡烛、进入合影或切后台，会关闭麦克风并释放资源，不自动重新申请。

### 点点玩

四个大角色按钮：**小龙、小牛、小鸡、拖拉机**。点一下会有招呼文字和轻轻跳动；开启声音后有对应短音效。小龙用柔和音符回应，小牛、小鸡和拖拉机使用合成音效。

没有分数、限时、失败或连续奖励压力。大人可以陪孩子指认角色，按孩子自己的节奏玩。系统“减少动态效果”或合影状态下会减少／停止动态反馈。

## 全屏、常亮与投屏边界

- 网页不直接连接电视；电视画面来自手机系统的屏幕镜像。
- 全屏与常亮仅在主动点击后申请，失败时显示回退提示。
- 常亮通常需要 HTTPS 等安全环境。GitHub Pages 提供 HTTPS；局域网 HTTP 预览不保证支持常亮或麦克风。
- 切到其他应用时，浏览器可能释放常亮。回到页面后会尝试恢复先前开启的常亮，以按钮状态为准。
- 部分手机浏览器不支持网页全屏，横屏并收起浏览器工具栏仍可展示。
- 操作栏在窄屏换行，设置展开后可滚动；合影和隐藏按钮会清除常驻操作提示。
- 现场网络、手机发热、系统锁屏、电视裁切与镜像清晰度需要用实际设备验证。

## 本地预览

电脑可直接打开 `index.html`，网站运行时没有外部网络依赖。手机能否直接运行本地 HTML 取决于系统，因此首次手机测试建议使用局域网服务器。

在项目根目录运行：

```bash
python3 -m http.server 8080 --bind 0.0.0.0
```

电脑访问 `http://localhost:8080`；手机与电脑连接同一局域网，访问 `http://电脑的局域网IP:8080`。电脑需要保持运行，防火墙需允许连接；结束后按 `Ctrl+C`。

## 发布到 GitHub Pages

项目提供工作流 [.github/workflows/pages.yml](.github/workflows/pages.yml)，不需要配置额外的发布密钥。

1. 站点已经上线；后续更新时，将项目源文件提交到实际部署仓库的 `main` 分支。若使用其他分支，先修改工作流的分支名称。
2. 在仓库 **Settings → Pages → Build and deployment → Source** 中选择 **GitHub Actions**。
3. 推送到 `main`，或在 Actions 中手动运行 **Publish birthday farm**。
4. 工作流先运行检查，再构建 `dist/` 和离线包，最后发布 Pages。
5. 成功后的网址由部署结果提供；常见项目站点形式为 `https://账号名.github.io/仓库名/`。

页面和素材均使用相对路径，适配仓库子路径。打包使用明确的文件清单，只发布实际使用的站点文件，不包含 `.git`、开发脚本、未引用的试验素材或个人文件。

工作流依据 [GitHub 官方 Pages 工作流文档](https://docs.github.com/en/pages/getting-started-with-github-pages/using-custom-workflows-with-github-pages) 配置。普通公开 Pages 站点会展示页面中的姓名；相册的本地选图不会随之公开。不要把私人照片、家庭视频加入发布清单。

当前线上地址为 `https://zemu2718.github.io/little-tractor-party/`。上线由用户确认；本地文档更新并不代表已同步推送到线上。后续发布以实际仓库的 Actions 部署结果为准。

### 修改画面后更新素材

```bash
python3 scripts/build_party_art.py
python3 scripts/build_play_art.py
python3 scripts/export_background.py
```

- 派对插画由 `build_party_art.py` 生成，复用简洁版拖拉机和 `assets/little-dragon.svg`。修改派对插画时优先改生成脚本，避免下次生成覆盖手动改图。
- 游乐园主画面和角色素材由 `build_play_art.py` 生成；其内嵌首页画面会同步更新。红色拖拉机源图已存入项目，后续生成不依赖原参考文件路径。
- `export_background.py` 更新派对版、简洁版两套 SVG／4K PNG，以及游乐园的 4K 预览图。
- PNG 导出需要系统提供 librsvg、Cairo 及中文字体；普通使用、检查和发布直接使用已有图片，不需要安装这些开发工具。
- 静态备用图采用初始姿态，不是当前动画帧；蛋糕图为蜡烛点亮状态。

检查覆盖场景与蜡烛状态、合影恢复、减少动态效果、音频停止、相册排序／循环／失败处理、图片资源释放、后台暂停、麦克风延迟授权取消、全屏回退、常亮生命周期及站点链接。

打包生成：

- `dist/`：GitHub Pages 发布目录，包含站点和离线包下载。
- `little-tractor-party-offline.zip`：首页、三个版本、全部运行素材、静态备用图及 README；无需联网加载外部资源。维护脚本保留在源码项目中。

以上两个输出不加入 Git，工作流会从最新源码重新生成。新增页面或资源时，同步更新 `scripts/package_site.py` 中的发布清单，并在修改后重新打包。
