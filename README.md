## 本地主画面使用说明

第一版入口是 `index.html`，使用原生 HTML/CSS/JavaScript 和内嵌 SVG 插画，无需安装依赖、构建或联网加载素材，不含照片、音乐、分析统计或上传功能。当前默认是更明亮的绿色、金黄与奶油色派对版；原有低饱和绘本风保留为简洁版。两者均尚未按大厅参考图校色。

- 在电脑浏览器中打开 `index.html` 即可预览。
- 如需手机访问，在本目录运行 `python3 -m http.server 8080 --bind 0.0.0.0`，手机连接同一局域网后，访问 `http://电脑的局域网IP:8080`。电脑防火墙需允许连接；此方式需电脑保持运行。结束后按 Ctrl+C 停止服务。
- 手机横屏后，使用系统的屏幕镜像功能投到电视；网页本身不发起投屏。
- 主画面保持 16:9 完整显示，其他屏幕比例会留边，不裁掉姓名或插画。
- 「暂停动画」可用于合影；「隐藏按钮」会立即清理操作栏和提示，轻点任意画面恢复按钮。电脑也可按 H 显示或隐藏按钮，Esc 恢复按钮。
- 「全屏展示」在支持 Fullscreen API 的浏览器中生效；不支持时会给出提示，请横屏并收起浏览器工具栏。
- 尊重系统的“减少动态效果”设置；默认静音，没有自动音乐。

页面可离线打开，但手机浏览器能否直接打开本地 HTML 文件取决于系统；首次手机测试建议使用局域网地址。现场仍需实测镜像清晰度、浏览器工具栏、电视边缘裁切及手机自动锁屏。尚未进行真实手机和电视测试。

### 合影模式与静态备用图

- 点击「合影模式」：暂停所有动画、立即隐藏按钮和提示，保留干净背景。
- 轻点画面或按 Esc 恢复按钮，画面仍保持静止；点击「退出合影」恢复进入前的动画状态。点击「继续动画」则直接退出合影并播放动画。
- 展开「更多设置与备用图」，点击「农场备用图」下载 `assets/birthday-background-4k.png`，尺寸为 **3840×2160（16:9）**。部分手机浏览器可能直接打开图片，可长按保存。建议活动前保存到手机相册，现场断网也可展示。
- 备用图含姓名、祝福及完整插画，没有按钮。PNG 固定了字体显示；另附可缩放的 `assets/birthday-background.svg`。
- 主画面文字与插画共用 SVG 坐标，横屏尺寸变化不会改变它们的相对位置。备用图使用动画初始姿态，并非当前暂停帧的截图。
- 分享或拷贝完整网页时，请一起保留 `assets` 目录；单独拷贝 `index.html` 仍可显示主画面，但备用图下载需要该目录。

修改插画或文案后，可运行 `python3 scripts/export_background.py` 重新生成备用图。导出脚本需要系统提供 librsvg、Cairo 及中文字体；日常打开网页和使用现成备用图不需要这些开发工具。

## 生日当天的操作顺序

1. 提前把两张 PNG 备用图保存到手机相册；也可使用 `little-tractor-party-offline.zip`，解压后打开其中的 `index.html`。不要直接在压缩包预览器里运行网页。
2. 打开网页，手机横屏，使用系统的屏幕镜像连接电视。默认展示「快乐农场」。
3. 展开「更多设置与备用图」，按需开启「保持屏幕常亮」或「全屏展示」。这两项都取决于浏览器支持；不支持时有明确提示，网页仍能使用。
4. 点击「隐藏按钮」，用农场动画作为迎宾背景；轻点画面恢复操作。隐藏后没有常驻操作提示。
5. 切蛋糕时，点击「生日蛋糕」，然后隐藏按钮。大家唱歌、许愿的节奏自行安排。
6. 准备吹蜡烛时，轻点画面恢复按钮，再点击「吹灭蜡烛」。蜡烛熄灭、祝福文案改变，按钮自动隐藏，轻柔彩纸只播放一轮。没有自动音乐、倒计时、麦克风或摄像头权限请求。
7. 需要重来时，轻点画面后点击「重新点亮」。切换农场和蛋糕会保留本次蜡烛状态；刷新网页则恢复默认状态。
8. 合照时，任一场景都可点击「合影模式」。此时会清除尚在飘落的彩纸，避免定格的彩纸挡住人物或文字。暂停动画或系统启用“减少动态效果”时，吹灭蜡烛仍生效，但不会播放彩纸。

### 常亮与全屏的实际边界

- 常亮默认关闭。仅在主动点击后请求屏幕唤醒锁，不播放隐藏视频或声音来阻止锁屏。
- 切到其他应用后浏览器可能释放常亮；重新回到页面时尝试恢复，按钮展示实际状态。请求失败时有提示。
- 常亮通常需要安全网页环境；局域网 HTTP 地址可能无法使用。此时请在手机系统设置里调整自动锁屏时间，活动结束后恢复。
- 操作栏在窄屏下换行，展开设置后可滚动。画面始终保持 16:9，不强制旋转设备，也不拉伸插画。
